# 研究发表成果

> **待审核译稿（draft）** · 译者：Codex · 人工审核：待定 · [英文参考原文](https://github.com/Open-Source-Research-Initiative/osri/blob/a7b0e61f1a33fece8873bc9574d747da0a7615b6/publications/README.md)

OSRI 支持期刊论文、完整会议论文、预印本，以及实质性的研究博客或技术文章。准确说明每项成果的同行评审状态。

按照[公开并登记研究成果](publish.md)完成提交、修改、保存和登记。

将已公开的成果加入 [publications.csv（英文记录）](../../../publications/publications.csv)。使用项目 ID、研究工作 ID 和单独的发表成果 ID。关联研究仓库与证据。

需要帮助时，向维护者提供公开链接、成果类型、项目与同行评审状态。维护者可以分配 ID 并补全记录。你可以从[成果分享区（Show and tell）](https://github.com/Open-Source-Research-Initiative/.github/discussions/categories/show-and-tell)开始。

按类型统计发表成果，并报告合计；同时统计独立研究工作的数量。一份预印本、对应的期刊论文和实质性的配套博客，可以是同一研究工作的三项成果。

编辑、镜像和预印本修订版本仍属于原有成果。一个项目可以包含多项独立研究工作。跨领域的研究工作在组织合计中只计一次。

按每项成果首次公开的日期计入年度统计。已被接收但尚未公开的工作保留在待发表记录中，公开后再登记发表。

公告和日常进度更新属于项目沟通。研究软件、模型与数据集可以支持发表成果，也可以成为实质性方法类成果的研究对象。

当前登记表只有列标题，尚未核实成果清单或总数。报告数量前，先加入有依据的记录。
