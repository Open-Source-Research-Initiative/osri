# 社区行为准则

> **待审核译稿（draft）** · 译者：Codex · 人工审核：待定 · [英文参考原文](https://github.com/Open-Source-Research-Initiative/osri/blob/a7b0e61f1a33fece8873bc9574d747da0a7615b6/CODE_OF_CONDUCT.md)

欢迎不同领域和技能水平的参与者。解释术语，提出问题，并尊重地讨论观点与证据。准确记录贡献并给予署名。

不得骚扰他人、未经许可公开私人信息，或歪曲证据与评审情况。讨论应与研究和协作相关。

涉及保密问题，请联系 [Cole](mailto:cole.lyons@pennmedicine.upenn.edu)。管理员可以删除有害内容或限制参与。你可以要求说明理由或重新考虑。目前尚未指定独立的申诉评审者。
