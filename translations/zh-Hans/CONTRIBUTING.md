# 参与 OSRI

> **待审核译稿（draft）** · 译者：Codex · 人工审核：待定 · [英文参考原文](https://github.com/Open-Source-Research-Initiative/osri/blob/30e7f170c95442a08da107934cdd5be64b1098ec/CONTRIBUTING.md)

从[研究入门指南](START_HERE.md)开始。在[问答区（Q&A）](https://github.com/Open-Source-Research-Initiative/.github/discussions/new?category=q-a)提问或申请公开资源，在[想法区（Ideas）](https://github.com/Open-Source-Research-Initiative/.github/discussions/new?category=ideas)提出研究主题。

你可以使用自己偏好的语言。[浏览器指南](docs/browser-setup.md)说明了登录、首次提交和项目设置。你可以请维护者把资料笔记或表格加入仓库。

你可以贡献问题、资料、解释、评审、写作、数据处理、代码或仿真。资料线索可以尚未核实。修正错字只需简短说明。维护者可以协助把建议落实为修改。

## 选择第一个贡献

| 你的兴趣 | 可以先做什么 |
| --- | --- |
| 刚开始参与 | 提问、指出难懂的段落，或修正链接。 |
| 领域知识 | 协助明确研究问题，或检查某种解释。 |
| 文献 | 寻找资料、核实引用，或按项目方法提取证据。 |
| 数据与方法 | 检查数据、复现计算、编写代码，或测试模型。 |
| 写作与评审 | 修改段落、检查方法，或对照证据评审主张。 |
| 语言与社区 | 翻译页面、审核译文、申请资源，或帮助其他参与者。 |

从[研究项目（英文）](../../projects/README.md)中选择一个小任务，或在问答区说明你能提供什么帮助。附上问题、资料或修改建议。维护者可以协助使用 Git 并确定下一步。

如果还没有适合参与的项目，可以[提供帮助](docs/find-help.md#寻找协作者或提供帮助)，或[尝试第一次资料比较](START_HERE.md#无须编程的第一个任务)。你无须独自发起一项完整研究。

已经在做研究？查看[如何加入已有项目（英文）](../../projects/README.md#bring-an-existing-project)。

## 提交修改与记录贡献

遵循 [OSRI-0.1.0](governance/contribution-standards.md)。说明任务、证据、已完成的检查，以及仍需进行的评审。记录智能体提供的实质性帮助。由人负责接受修改并授权公开。

用 issue 跟踪已商定的任务，用拉取请求提交修改。关联相关讨论和研究项目。涉及保密事项时，请联系 [Cole](mailto:cole.lyons@pennmedicine.upenn.edu)。

按照[协作与评审指南](docs/find-help.md)寻找协作者或评审者，并确认负责下一步的人。随着工作推进讨论贡献角色与作者署名。提交成果前确认署名。

遵循[写作](governance/writing-style.md)、[翻译](governance/translation.md)与[视觉识别](governance/visual-identity.md)指南。

已接受的工作可以加入[贡献记录板（英文）](../../community/ACTIVITY.md)。请维护者登记记录，并使用你选定的公开署名。
