# 用浏览器参与研究

> **待审核译稿（draft）** · 译者：Codex · 人工审核：待定 · [英文参考原文](https://github.com/Open-Source-Research-Initiative/osri/blob/main/docs/browser-setup.md)

阅读公开指南不需要账户。发帖或编辑文件前，请登录 GitHub。无须终端、智能体或安装软件。

## 提交第一项贡献

1. 选择一个小任务，例如[第一次资料比较](../START_HERE.md#无须编程的第一个任务)。
2. 打开 [OSRI 问答区（Q&A）](https://github.com/orgs/Open-Source-Research-Initiative/discussions/new?category=q-a)。
3. 使用类似 **First contribution: [问题或任务]** 的标题。
4. 粘贴笔记或表格。附上资料链接，并标明尚未核查的材料。
5. 请维护者把内容加入项目，并安排评审。

帖子和附件都是公开的。只分享可以公开的材料。如需保密协调，请先[联系 Cole](mailto:cole.lyons@pennmedicine.upenn.edu)，再发送文件。

请维护者确认项目、负责下一步的人，以及获接纳的笔记将记录在哪里。发帖本身不代表贡献已被接纳。你可以使用自己偏好的语言。

## 创建项目

1. 打开[项目模板](https://github.com/Open-Source-Research-Initiative/project-template)。
2. 选择 **Use this template**，再选择 **Create a new repository**。
3. 将自己的账户选为所有者，或请管理员创建 OSRI 仓库。
4. 选择名称和可见性，再选择 **Create repository from template**。公开仓库会公开其中的文件与历史记录。
5. 在新仓库中打开 `README.md`，使用铅笔按钮编辑。
6. 填写问题、人类负责人、范围、当前状态和第一个任务。完成后删除设置提示。
7. 预览修改。按照[下方的修改步骤](#提出文件修改)请求接纳。
8. 打开 **Issues**，再选择 **New issue**。说明第一个任务、预期结果和所需帮助。
9. 将仓库链接发给管理员，申请项目 ID 并加入项目目录。

如果某个选项不可用，请在 Q&A 中请维护者协助。当前界面请参阅 [GitHub 模板说明（英文）](https://docs.github.com/en/repositories/creating-and-managing-repositories/creating-a-repository-from-a-template)。

## 提出文件修改

提交（commit）保存一个文件版本。分支（branch）把拟议修改与现有工作分开。拉取请求（pull request）用于请维护者评审并接纳修改。

编辑文件后，选择 **Commit changes**。选择新分支，并按提示创建拉取请求。说明任务、资料、实际完成的检查和尚需开展的评审。关联相应的 issue 或讨论。

如果没有写入权限，GitHub 可能会请你派生仓库（fork），即在自己账户中创建副本。按提示提出修改。[GitHub 文件编辑指南（英文）](https://docs.github.com/en/repositories/working-with-files/managing-files/editing-files)说明了这两种方式。

你也可以把拟议文本发在项目 issue 或 Q&A 中。请维护者准备文件修改，并确认如何记录你的贡献署名。
