# OSRI Simulation Lab

The lab is a shared research capability under development. It supports virtual experiments across OSRI's areas, including processes normally studied in physical laboratories.

Begin a simulation study in its own project repository. Choose a model that fits a defined question. Record its source, inputs, assumptions, software version, configuration, and results.

Use the [simulation workflow](../tooling/workflows.md#simulation-or-replication) and [resource catalog](../resources/README.md). Keep implementation checks, benchmark agreement, and evidence about observed systems distinct. State the conditions under which findings hold.

Extract reusable models, environments, or benchmarks when several projects need them. A separate simulation-lab repository can hold those capabilities when ready. Its existence is not required to start a bounded computational study.
