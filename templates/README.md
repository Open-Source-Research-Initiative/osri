# Optional working templates

Use only the detail your task needs. A question or unchecked source lead needs no full form.

- [Fuller project brief](project-README.md): an optional example for question, lead, scope, methods, and evidence.
- [Research task](research-task.md): inputs, outputs, checks, and pending review.
- [Change description](pull_request_template.md): explain a proposed contribution.
- [Agent instructions](AGENTS.md.template): adapt the project-specific setup.
- [Public resource request](resource-request.md): public metadata only.
- [Private request record](resource-request-private.md): use the agreed private route and storage.

The [project-template repository](https://github.com/Open-Source-Research-Initiative/project-template) is the starting kit for a new project. The fuller brief is optional.
