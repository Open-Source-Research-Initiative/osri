# Repository roles

| Repository | Role |
| --- | --- |
| [osri](../README.md) | Entry guide, area indexes, project directory, publication records, standards, and administrative meta-research. |
| [project-template](https://github.com/Open-Source-Research-Initiative/project-template) | Small starting structure for each research project. |
| [.github](https://github.com/Open-Source-Research-Initiative/.github) | Organization profile, shared community templates, and the public Discussions forum. |

Each research project gets a separate repository. Its README holds the question, human lead, scope, and current research state. Its issues and pull requests hold tasks and proposed changes.

Area pages link to projects rather than copying their research. The hub publication register links related outputs. Meta-research is part of administering the whole group.

Start with the project template's few files. Add data, analysis, models, and result folders only when the work needs them. Keep large or restricted artifacts in an approved location and track permitted metadata and provenance.

The [Simulation Lab](../simulation-lab/README.md) is under development. A separate repository can hold shared capabilities when they become useful. An organization Project can provide an overall task view later.

New project setup includes a human lead, shared standards version, licenses and data terms, and repository access settings. Template files do not replace access controls or branch settings. The initial publication uses branch protection without a required second reviewer, because OSRI currently has one founder.
