# Initial starter-kit publication

Date: 2026-11-13. Version: OSRI-0.1.0.

The founder requested publication of the reviewed starter kit and creation of the osri hub and project-template repositories.

The initial shared rules are published as OSRI-0.1.0. The v0.1.0 tag identifies this baseline. Projects record the exact baseline commit they use.

The founder selected CC BY 4.0 for original guides and catalogs, and MIT for original code and configuration. Third-party articles, data, models, software, and license notices retain their own terms.

The main path is a short research guide. Tools and plugins are optional. The existing .github Discussions forum remains the shared public conversation space.

Each research project gets one repository. The hub holds the directory, rules, resources, publication records, and administrative meta-research. A shared Simulation Lab remains under development.
