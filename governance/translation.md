# Translation

Contributors may use their preferred language. English is the initial reference version for shared guides.

## Languages

- **Initial candidates:** Spanish, Simplified Chinese, Hindi, Arabic, French, and Brazilian Portuguese.
- **Other candidates:** Bengali, Urdu, Indonesian, Russian, German, and Japanese.

Other languages are welcome. Adjust the order for contributor needs and available reviewers.

Start with READMEs, the getting-started guide, contribution rules, resource requests, and the project template. Then translate other guides and project summaries as needed.

## Prepare a translation

1. Use UTF-8 Markdown in `translations/<language-tag>/<source-path>`, such as `translations/es/START_HERE.md`.
2. Record the source path, source commit, language tag, translator, reviewer, and review date.
3. Preserve scientific meaning, uncertainty, values, units, identifiers, code, and file paths.
4. Use natural technical language. STE guides English writing; other languages have their own conventions.
5. Translate captions, link descriptions, and alt text. Check fonts, line wrapping, and right-to-left text.
6. Show language names in their own languages. Use text links rather than flags.

Keep **OSRI** and **Agentic-Powered-Research** unchanged. Add a local explanation where needed.

## Review and update

Agents may draft translations. A fluent person must compare the translation with its source. Rules, methods, and scientific claims also need relevant subject expertise.

Label each page **draft**, **reviewed**, or **needs-update**. Mark affected translations when the source changes. If versions conflict, ask a maintainer to resolve the passage against the reference source.

Keep attribution and license notices. Ask for help in [Q&A](https://github.com/Open-Source-Research-Initiative/.github/discussions/new?category=q-a).
