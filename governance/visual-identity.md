# Visual identity

Use one OSRI identity across repositories, research areas, the Simulation Lab, and meta-research. Final logos, colors, and fonts are still being selected.

## Name and graphics

- Use **Open Source Research Initiative** and **OSRI**.
- Use the descriptor **Human-driven Agentic-Powered-Research**.
- Derive avatars, headers, icons, and publication cards from the same logo and layout rules.
- Keep editable sources. Use SVG for vector graphics, PNG for raster images, and PDF for print copies.
- Record creators, versions, font dependencies, and reuse terms.

## Readability

- Keep README instructions and navigation as selectable text.
- Give informative graphics alt text and complex figures a text explanation.
- Use fonts that support the required scripts. Allow translated labels to wrap.
- Check small screens, light and dark backgrounds, monochrome output, and right-to-left layouts.
- Show status with words or shapes as well as color.
- Use at least [4.5:1 contrast for body text](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html).
- Use at least [3:1 contrast for essential graphical elements](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html) against adjacent colors.

## Research figures

Label axes, units, uncertainty, and sources. Preserve formal notation and relationship direction. Label illustrations and synthetic examples. State publication and review status accurately.

Keep plotting code and model sources with the research project. Follow the [open-format guide](open-formats.md) and the publication venue's requirements.
