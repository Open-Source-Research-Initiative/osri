# First contributor task packets

These original planning packets are now [six published issues](published-issues.json), with a named human maintainer, claim instructions and optional public credit. Follow the live issue for current status. The timebox is a suggested first attempt, not a guarantee that a publisher page will be accessible. Stop and record an unresolved check rather than invent a finding.

## 1. Try a publication shortlist for your own research

- **Who:** a researcher with a current or planned paper; no coding required.
- **Start:** [directory](https://open-source-research-initiative.github.io/venues/).
- **Timebox:** 10–15 minutes.
- **Return:** the research field and article type, a comparison URL for up to three venues, one plausible fit or reason none fits, and one obstacle or helpful detail.
- **Acceptance:** the report describes actual use and provides an actionable observation. A visit or unsubstantiated “looks good” is not automatically an accepted task. This can recruit several pilot participants; maintainers create distinct task records only for distinct, accepted contributions.
- **Privacy:** a public topic description is enough; no manuscript upload is needed. Ask before quoting the experience publicly.

## 2. Independently check Research Ethics author costs

- **Who:** someone comfortable reading author instructions.
- **Start:** [official submission guidelines](https://journals.sagepub.com/author-instructions/rea).
- **Timebox:** 15 minutes.
- **Return:** submission cost and standard publication cost separately; relevant article-type, page, membership, language or optional-OA conditions; source URL and date checked. State any element not established.
- **Acceptance:** the note accurately distinguishes free author costs, optional services and reader access, with readable applicable evidence. Confirmation of the existing record is useful; do not manufacture a correction.
- **Maintainer work:** independently check the note and prepare any dated follow-up evidence without rewriting the old cost campaign.

## 3. Verify JOSS AI-disclosure instructions

- **Who:** a researcher or research-software contributor; no coding required.
- **Start:** [JOSS submission guidance](https://joss.readthedocs.io/en/latest/submitting.html).
- **Timebox:** 20 minutes.
- **Return:** what AI use the policy addresses, what must be disclosed, where the disclosure belongs, and the exact official section URL and check date. Preserve conditions; do not generalize permission beyond the text.
- **Acceptance:** another reader can follow the source and reproduce the interpretation. Any unclear permission remains unclear. This is a policy check, not scientific review of a submitted software paper.

## 4. Resolve International Relations editorial-board evidence

- **Who:** someone able to inspect a journal's current board page.
- **Start:** [official editorial board](https://journals.sagepub.com/editorial-board/ire).
- **Timebox:** 20 minutes.
- **Return:** one current named editor, role and affiliation where stated, with official source and check date; otherwise describe the access or identity problem.
- **Acceptance:** the record matches International Relations, not a similarly named journal, and does not invent a missing affiliation. Useful new evidence or a substantive access finding is reviewed on its merits.
- **Maintainer work:** evaluate whether this resolves the recorded board gap; a submitted note alone does not change directory status.

## 5. Trace one Journal of Physics D publication

- **Who:** someone comfortable locating an article and DOI.
- **Start:** [official journal information](https://publishingsupport.iopscience.iop.org/journals/journal-of-physics-d-applied-physics/).
- **Timebox:** 15–20 minutes.
- **Return:** one recent research article's title, DOI, journal identity, publication date if available, and a publisher landing page or exact-journal Crossref metadata record.
- **Acceptance:** the article belongs to Journal of Physics D: Applied Physics. State whether the check used a publisher page or metadata only; it does not establish scientific validity or actual review conduct.

## 6. Check a three-venue shortlist against scope and article types

- **Who:** a public-health, health-services, education or behavioral researcher familiar with the relevant work.
- **Start:** the directory's default view filtered to the participant's field.
- **Timebox:** 20–30 minutes.
- **Return:** a comparison URL, three official scope/article-type links, and a brief reason each venue fits or should be excluded for a clearly described research example. Distinguish personal assessment from the venue's stated rules.
- **Acceptance:** the reasoning is source-backed, identifies meaningful fit or restrictions, and makes no acceptance-probability claim. A publishable walkthrough requires permission for any participant-specific research description or quote.

## Common review and credit

Claim one task at a time. Submit a short source note through the issue form or agreed email route; a pull request is optional. Codex supports source checking and patch preparation. Cole makes the human maintainer's acceptance decision. Record material agent assistance. Public credit is optional, authorship is separate, and one task is not split into multiple contribution counts merely because it has several URLs or revisions.
