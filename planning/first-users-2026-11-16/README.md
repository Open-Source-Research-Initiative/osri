# First launch package

Versioned launch plan, six published issue packets, unsent outreach drafts, an empty pilot-log template, and verification evidence for the November 16, 2026 launch. These are planning records; the researcher-facing entry points are linked below.

## Working documents

- [Launch plan](PLAN.md): audiences, ownership, sequence and targets.
- [Outreach drafts](OUTREACH-DRAFTS.md): two researcher invitations, an introduction request, one follow-up, LinkedIn and OSRI announcements, and a contributor-recruitment comment. All remain unsent outreach drafts; replace bracketed details truthfully before use.
- [Starter-task packets](STARTER-TASKS.md) and [six published issues](published-issues.json).
- [Empty pilot-log template](pilot-log.template.csv): start a local working copy for participant-ID-based tracking. Completed logs and private contact information do not belong in this public repository. Agent checks do not count as external researcher use.
