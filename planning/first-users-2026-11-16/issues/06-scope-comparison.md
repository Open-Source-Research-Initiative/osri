# First task: check the scope and article types of a three-venue shortlist

## Goal

Help a researcher distinguish relevant venues from superficially similar ones using official scope and article-type guidance.

**For:** a public-health, health-services, education or behavioral researcher. **First attempt:** 20–30 minutes.

## Start

Use the [directory](https://open-source-research-initiative.github.io/venues/) in its default mode, filter to your field and compare three venues for a clearly described public research example.

## Return

- The research example, field and intended article type, plus the comparison URL.
- Three official scope/article-type links, one per venue.
- A brief source-backed reason each venue fits or should be excluded. Include important author, research-focus or article-type restrictions.
- Which statements are the venue's rules and which are your own assessment.

## Acceptance

A comparison that identifies meaningful fit or restrictions and makes no acceptance-probability claim. It can become a public walkthrough only with permission for any participant-specific description or quotation. This scope check is distinct from the shorter interface trial: do not count the same work twice.

Claim one task at a time; the launch starts with at most three active claims across these issues. The timebox is a suggested first attempt. If a source is blocked or unclear, report that limit.

Reply here with a short note and source links. **No code, installation, fork or pull request is required.** Include the date checked and any material AI/agent assistance. Please use only information you may share publicly; a public research-topic description is enough.
