# Research publications

OSRI supports journal articles, full conference papers, preprints, and substantive research blogs or technical essays. State each output's peer-review status accurately.

Add public outputs to [publications.csv](publications.csv). Use a project ID, a research-work ID, and a separate publication ID. Link the output to its research repository and evidence.

If you need help, send a maintainer the public link, output type, project, and peer-review status. They can assign IDs and complete the record. You can start in [Show and tell](https://github.com/Open-Source-Research-Initiative/.github/discussions/categories/show-and-tell).

Count publication outputs by type and report their combined total. Also count distinct research works. A preprint, its journal article, and a substantive companion blog can be three outputs from one work.

Edits, mirrors, and revised preprint versions remain part of the existing output. A project can contain several distinct research works. A work spanning areas counts once in the organization total.

Use the first public date for each output's annual count. Keep accepted work awaiting public publication in the pipeline. Record its publication when it becomes public.

Announcements and routine progress updates remain project communication. Research software, models, and datasets can support publications or become the subject of substantive methods outputs.

The register begins with column headers. No publication inventory or total has been verified. Add supported records before reporting a count.
